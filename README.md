# Rock-Paper-Scissors Game

A simple Rock-Paper-Scissors game made using HTML, CSS, and JavaScript.

## Features

- Choose Rock, Paper, or Scissors.
- Computer randomly selects a choice.
- Displays both the player's and computer's choices.
- Shows whether the player wins, loses, or gets a tie.
- Interactive buttons with hover effects.

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The player selects one of the three choices. JavaScript randomly generates the computer's choice and compares both choices to determine the result.
